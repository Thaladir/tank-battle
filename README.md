# 🎮 超级坦克大战 · Tank Battalion

> 一款运行在浏览器里的像素风街机坦克对战游戏，支持单人挑战 AI、本地双人和局域网联机三种模式。

## 功能特性

- 🤖 **三难度 AI**：简单 / 普通 / 困难，困难模式会预判走位、开火后横移
- 👥 **本地双人**：同一台电脑两名玩家分屏操控
- 🌐 **局域网联机**：WebSocket 实时对战，支持跨设备连接
- 🏆 **7 局 4 胜制**：每局结束后双方各选一张增幅卡，越打越强
- 🗺️ **多样地形**：砖墙、钢墙、水面、草丛，策略性十足
- 🎵 **像素音效**：Web Audio API 合成，全程无需加载资源

## 操作说明

| 操作 | 玩家 1 | 玩家 2（本地双人）|
|------|--------|-----------------|
| 移动 / 转向 | `W A S D` | `↑ ← ↓ →` |
| 射击 | `空格` | `Enter` |
| 选择增幅 | `A / D` 切换，`空格` 确认 | `← / →` 切换，`Enter` 确认 |
| 暂停 / 继续 | `Esc` | — |

> 联机模式双方均使用 `WASD + 空格` 操作。

## 增幅系统

每局结束后，双方各从三张随机卡中选一张，每张最多叠加 3 次：

| 图标 | 名称 | 效果 |
|------|------|------|
| 🔥 | 急速射击 | 射击冷却缩短 100ms |
| 💥 | 穿甲弹 | 穿过并损伤砖墙，伤害 +5 |
| ❤️ | 钢铁之躯 | 生命上限 +40 |
| ⚡ | 氮气加速 | 移动速度 +1.5 |
| 🛡️ | 能量护盾 | 每局格挡一次伤害 |
| 🌪️ | 三连发 | 齐射 3 / 4 / 5 发（叠加） |
| 🔰 | 装甲护盾 | 每层 20 点护盾，每局补满 |
| 🔁 | 反弹专家 | 钢墙反弹次数 +2 |
| 🚀 | 超速子弹 | 子弹速度 +6 |
| 🩸 | 吸血炮 | 命中敌方每次回复 20 HP |
| 🏗️ | 工兵坦克 | 行进时身后自动建造砖墙 |
| 🌀 | 追踪导弹 | 每两发一发自动追踪目标 |
| ⚔️ | 双管炮 | 同屏子弹数量上限 +2 |

## 局域网联机方法

1. 在游戏主界面点 **联机对战** → **下载 server.js**
2. 安装 [Node.js](https://nodejs.org/)（LTS 版本）
3. 在 server.js 所在目录打开终端，运行：
   ```bash
   node server.js
   ```
4. 看到 `Tank Battalion · WebSocket port 8080` 说明服务器已就绪
5. 房主在游戏里创建房间，把**房间号**和**局域网 IP** 告诉对方
6. 对方在地址栏填 `ws://房主IP:8080`，输入房间号加入

> 查看局域网 IP：macOS 按住 `Option` 点菜单栏 Wi-Fi 图标；Windows 在终端运行 `ipconfig`

## 技术栈

- 纯 HTML + CSS + JavaScript，零依赖，单文件
- Canvas 2D 渲染（像素风格，`image-rendering: pixelated`）
- Web Audio API 程序化音效合成
- WebSocket 联机，自定义轻量 Node.js 中继服务器（内嵌于 HTML 注释中）
